# BYOP P12 设计权威摘要

版本：0.3.0 · 日期：2026-10-24 · 状态：P12 设计与 token、现有页面和模型渠道流程已实施；应用 0.12.0。本页是仓库发布摘要，详细设计位于项目根 `../../../../design-system/pi-workbench/`；本目录只发布本摘要和两份 token 文件。

## 权威来源与视觉边界

[tokens.json](tokens.json) 是 BYOP Radix 产品数值的唯一权威，仓库发布副本必须逐字节一致。来源固定在 Radix Colors 官方 commit `dbdb85470547c7d34b9001f48fddb08ded335979`，MIT 许可文本已登记在根目录 `THIRD_PARTY_NOTICES.md`；产品读取其 palettes 数值，不自动跟随上游更新。[tokens.extensions.json](tokens.extensions.json) 只保留兼容、迁移和非冲突组件几何，不得覆盖产品值。Onevra 原始 token 只读，保留来源与历史，不代表当前产品数值。

| 项 | 当前口径 |
|---|---|
| 字号 | 仅 12/14/18px；辅助 12、正文和代码 14、标题 18 |
| 边框与圆角 | 可见边框 0.5px；输入 8、浮层 12、小 chip 6 |
| 间距与动效 | 4/8/12/16/24px；必要过渡 250ms ease-out，减少动态 0 |
| 材质 | Liquid Glass 只用于标题、导航和必要浮层；阅读区与 Composer 不透明。Glass 材质只有一个由 MyGo 着色器绘制的 1px optical rim，这是着色器内部光学边缘限制，不是应用 CSS/UI 边框，也不额外替代用户指定的 0.5px 可见边框；应用边框仍使用 0.5px |
| 回退 | 高对比、减少透明度或不支持玻璃时使用不透明 Radix 实色 |

## 当前页面与冻结候选

当前入口为 Chat、Plugins、Automations、Settings。设置提供统一搜索，About 位于页面底部。当前简单侧栏只是实施基底，A/B/C 布局尚未由用户选定。

Library 与 Document 已从 manifest 当前入口移出，保留为冻结候选。其页面、组件、文件冲突和引用契约继续作为历史设计证据，供未来业务插件重新授权时评估；当前不增加占位页、死按钮或实施范围。

Automations 只统一 P7 已登记项目、运行历史、失败暂停和恢复。P12 不新增 Loop 调度器、不解析 `/loop`、不预建 LoopEditor 或 LoopChip。旧调度规则只保留为历史和兼容 token，不能写成已完成。

## 模型、导入与设置

模型与渠道按 P11b 共用选择和管理流程：当前对话模型、上下文、思考档位和快速模式分别受实际 Pi 能力约束。新对话默认值仍未决，不新增独立页面，也不改变 Pi 启动默认语义。HUD 显示项开关未实现，本轮不添加。

HUD 平均输出速度按 §11.7：会话累计有效输出 Token ÷ 累计有效生成时长，不把工具等待或整轮用户等待计入；缺少可信计时时显示未知，不用 0 代替。

`models.json` 导入保存后先显示“待刷新”，不能把 Pi 当前进程的目录快照当成重载成功。空闲时重启 Pi 连接，重启前保存会话文件、渠道与 Model ID、思考档位、会话模型记忆和输入草稿；连接后依次恢复 `switch_session`、`set_model`、`set_thinking_level`，读回状态和目录后才标成功。任一步失败保留已保存状态，显示待核对与重试；运行中延后刷新，不中断任务。不能直接调用会清空会话的 `reconnectPi`。
