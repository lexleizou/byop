# P15b 轻量表格界面与日常使用

日期：2026-10-28。应用版本：0.15.0。开发：DeepSeek V4.1 Flash；定向复审：Claude Opus 5.5。

## 本阶段交付

普通 BYOP 启动自动发现轻量表格插件、侧栏入口与 Pi 会话扩展。插件数据保存在独立 plugin-data 目录，页面与 MCP 共用 SQLite 数据层，通过 WAL 访问。正常使用不需要环境变量；P15a 显式路径保留为开发入口。

| 功能 | 实现 |
|---|---|
| 表格 | 固定银行字段，横向滚动，100 行分页 |
| 查询 | 文本搜索、单条件类型筛选、排序、全部匹配记录的精确本金合计 |
| 编辑 | 单格 Enter 保存、Tab 保存并移动、Escape 取消，新增与删除 |
| 批量 | 已选记录或全部筛选结果设置一个字段 |
| Agent | 固定记录上下文 → 普通聊天的可移除标签 → 发送时追加机器引用 → Pi 会话 MCP |
| 历史 | 页面与 Agent 来源、显式撤销；后续版本变化时整笔撤销拒绝 |
| 刷新 | 可见页面按版本轮询；有未提交编辑时保留草稿 |

页面命令使用 view_instance_id + client_command_id；Agent 继续使用真实 Pi session/user-message ID。写入与成功回执在同一事务；重复请求复用回执。上下文保存固定行 ID 与版本，不在应用修改时重跑筛选扩大目标。

## 已执行的验证

使用当前源代码的临时 QA 构建，通过真实 MyGo WebView 的 Page.Eval 驱动真实 DOM 事件和插件 RPC，并抓取实际原生页面。没有使用浏览器 mock。QA 驱动和数据只放 AgentScratch，不是产品接口。

| 项目 | 实际结果 |
|---|---|
| 启动 | 16 条合成记录显示、中文控件与版本轮询正常 |
| 搜索与排序 | 搜索单条命中，本金合计 1000.00；本金降序符合预期 |
| 单格编辑 | Enter 保存，行版本递增 |
| 批量设置 | 选中两行一起修改成功；本金 >= 15000 的筛选结果为两条、合计 31000.00，全部筛选结果批量修改成功 |
| 新增、删除、撤销 | 新增后删除，历史撤销恢复；批量修改撤销成功 |
| 普通聊天 | 点击发送到对话切页、填入文本并显示两条记录标签；发送后清除附件，界面隐藏机器 ID |
| 真实 Agent | DeepSeek V4.1 Flash 调用 table_query 与 table_change，仅更新所选两条记录；数据库来源与真实 Pi 用户消息 ID 一致 |

真实窗口验证发现并修复了自定义 URL scheme 下语言包 fetch 失败、ready 标记变量引用错误、选择列多余省略号。最终定向复审剩余 P0–P2 为 0：修复编辑中重绘导致的草稿/轮询问题、会话列表标题暴露机器引用问题，并同步宿主插件版本号。批量面板打开时固定目标与版本；外部修改后的应用请求按版本冲突处理，保留输入。

## 数据与发布边界

真实银行初始化使用此前只读导出的 16 条原始 seed；只读逐字段核对全部一致，金额按 SQLite 整数分与 seed 精确小数元换算比较，正式库 operations=0；不采用含两条试验新增记录的 P15a 测试数据库。正式插件数据库与源扶摇账本独立，源数据库未修改。公开截图和仓库 fixture 仅使用合成数据。

CSV/XLSX 导入导出、列管理、保存视图、公式与完整 Excel 兼容不在本阶段。当前表格为固定银行字段；未知枚举值保留原值。已执行操作检查不代表压力测试或全部未来使用场景。

MyGo window.CapturePage 不能合成独立 WKWebView 图层，故表格截图使用 WebView.CapturePage；聊天截图使用原生窗口截图。两者均来自实际应用运行。

## 最终复测与安装

- 在真实 WebView 中，编辑后勾选记录保留输入；外部独立命令写入后，版本轮询标记待刷新，Escape 关闭最后一个草稿后立即显示新值。
- 版本冲突后，显式 Refresh 保留输入并读取最新版本，随后 Enter 保存成功；自动刷新仍等待草稿结束。
- 批量面板打开后外部修改，Apply 返回冲突，固定 context、面板和输入保持。
- 宿主版本由 appVersion 统一提供，与插件最低版本 0.15.0 一致。
- 最终构建已安装到 `/Applications/BYOP.app`；原 0.14.0 应用保存在本机废纸篓，可恢复。
- 发布文件已安装到 `~/.byop/plugins/local.lightweight-table`。正常应用启动未设置表格专用环境变量，通过系统应用入口启动后，实际点击侧栏“表格”，正常显示 16 条真实记录，Pi 显示已连接。此步骤只读，没有发送修改数据的 Agent 消息。
- 正式数据库为 `~/.byop/plugin-data/local.lightweight-table/tables.sqlite`，与原导出业务值一致，operations=0。
- 本阶段不是完整 v0.5：文件导入导出等后续范围仍未实现。
