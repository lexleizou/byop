# P20 扶摇汇总面板与模型选择器图标对齐

日期：2026-10-29。基线：`10554b3`。应用：`0.18.6`。插件：`local.lightweight-table` 0.4.2。

## 已实现

- 模型选择器每行改为顶部对齐，修掉 P19 遗留的对不齐：行容器原先垂直居中两行内容，图标仍落在整行中间；现在整行 Start 对齐，品牌图标与选中勾落在模型名那一行，副标题（渠道 · 上下文）垂在其下，各行图标在同一竖线上。
- 扶摇页面查询栏上方新增汇总面板（`table.dashboard`）：三张合计卡（合同本金、剩余应还、实际已付）与“常用查询”按钮组。
- 预设按钮共 11 个：全部记录、逾期、还款中、已结清、到期或 30 天内、未建立计划、银行、网络金融平台、金融类、高息借款、亲友借款。每个按钮只带一个筛选条件，点击后把该条件写进原有筛选栏，按钮上的条数与列表底部的“匹配 N 条”来自同一份行数据与同一套筛选代码，不会出现两处数字不一致。
- 按钮文字取自该列枚举值的现有语言包，与表格、详情抽屉里的同一值同词；“全部记录”和“30 天内到期”用面板自有文案。当前生效的预设按钮保持按下态。
- 合计卡按整表汇总，每卡只用自己那一列，不拼出新的口径；金额沿用源数据的分单位整数换算，不做二次四舍五入。
- 汇总读取失败只提示一条错误，表格照常显示。刷新按钮同时重载表格与汇总；查询结果的数据版本与面板不一致时重载一次面板。
- 面板样式只用现有 `--byop-*` 主题变量与既有按钮样式，随 BYOP 主题（Light／Dark／高对比）与外观预设切换，无自有配色。
- 宿主与插件语言包各补 6 个键（`dashboardAria`、`dashboardPresetsTitle`、`dashboardPresetCount`、`dashboardPresetDueSoon`、`dashboardPresetHint`、`column.actual_paid`），中英文键集一致。

- “到期或 30 天内”按单边上界实现（下次应还早于今天 +31 天），因此已逾期且仍有下次应还日期的记录也会计入该按钮；本次 49 行数据中该 5 条的下次应还日期均已过期。按钮文案与该口径一致，且与筛选栏显示的日期一致。
