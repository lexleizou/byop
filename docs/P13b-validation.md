# P13b - Window and List Interaction Fixes

日期：2026-10-26。版本：0.13.2。基线：b5a03f2 (0.13.1)。

## 范围与实现

| 用户反馈 | 本次实现 |
|---|---|
| 窗口无法鼠标拖动 | 标题栏空白、标题胶囊外沿接入原生 DragWindow；拖动区域补齐高度。已加载会话的标题文字仍打开会话菜单，编辑和切换按钮保持交互 |
| 侧栏无法调宽 | 在导航与主区域之间的间隙加入 8px 拖动区域和横向调宽光标；展开宽度 160–360px，松开后保存，折叠保留展开宽度；同时扣除右侧任务栏和间隙，给聊天主区域保留至少 400px |
| 会话列表拥挤、分组不清 | 行间距 4px、列表上下留白 8px、日期标题留白；置顶与普通会话、稍后、归档之间增加线上 12px、线下 8px 留白和 0.5px 分隔线，归档展开高度跟随新行距 |
| 模型列表拥挤、长名称不全 | 条目最小高度 56px、上下内边距 8px、名称与副标题间距 4px；按最长名称实际字体宽度扩展菜单，受窗口可用宽度约束，保持单行和完整名称悬停提示 |

宽度改变同步到聊天区域、HUD 与设置页宽度计算。沿用原有窄窗口折叠行为，未增加新设置页。未修改 Pi 历史文件或凭据。
