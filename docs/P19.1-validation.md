# P19.1 Node.js 运行时查找

日期：2026-10-29。基线：`ac82bad`。应用：`0.18.5`。插件：`local.lightweight-table` 0.4.1（未改动）。

## 问题

从访达或启动台打开 BYOP 时，插件页显示“Node.js ≥25 not found: executable was not found in PATH”，卡片状态为“失败”。原因是 GUI 启动的进程 PATH 不含 `/opt/homebrew/bin` 等安装目录，而插件运行时只用 `exec.LookPath("node")` 查找。Pi CLI 早已有常见安装目录与登录 shell PATH 兜底，Node 运行时没有。

## 已实现

- `nodeRuntime` 的查找顺序与 Pi 一致：`BYOP_NODE` 显式设置 → 当前进程 PATH → 常见安装目录 → 登录 shell PATH。
- 只缓存成功结果；查找失败不再永久锁定，登录 shell 探测完成或用户补装 Node 后，“重新加载／重启插件”即可成功。
- 错误文案说明已查找过 PATH 与常见 Node.js 目录。`BYOP_NODE` 写成裸命令且找不到时，仍按用户设置的值报告版本检查结果。

- 修复前构建：插件登记为 registered，但 Node 解析返回截图中的原错误。
- 0.18.5 修复构建：Node 解析无错误，打开扶摇页面成功，WebView 读出 2 行合成记录，标题“扶摇”。
- 安装到 `/Applications/BYOP.app`，版本 `0.18.5`，`codesign --verify --deep --strict` 通过，可执行文件与 `dist` 产物 SHA-256 一致；旧版本移入 `~/.Trash`。

## 已知限制

- 未验证完全无 Node.js 的机器上的提示文案与恢复路径。
- 修复只在宿主启动时探测一次登录 shell PATH（结果缓存），因此新装 Node 后仍需一次插件重载或重启应用。
