# P27：决策落实与 Mermaid 渲染 MVP

日期：2026-11-06。用户依据 2026-11-05 决策授权实施。初始设计在开发前写于 `~/AgentScratch/20261106-byop-p27/spec.md`，本文保存交付范围与接口设计；验证结果另见 P27-validation.md。

## 已确认范围

- 保持 A 简洁侧栏；已启用插件长期超过 8 个时评估 B。
- 新对话的模型、渠道和思考档位跟随 Pi 有效状态，不增 BYOP 跨新会话默认记忆或独立设置页；恢复已有会话仍保持其状态。
- HUD 显示项开关暂缓。
- 首批实现 Mermaid 渲染插件，其他冻结候选不扩展。

## 用户流程

用户在 Plugins 安装 `plugins/mermaid-diagram` 文件夹或其 ZIP 包，从侧栏打开 Mermaid，粘贴源码并点击渲染，查看 SVG、放大/缩小/适应宽度，再编辑源码重新渲染。中文流程图、时序图与 Agentflow 为代表性验收输入；Agentflow 只表达流程，不执行任务。

本阶段使用现有 Plugin API 1、Node 生命周期、隔离主 WebView 与主题/语言桥。宿主无需新贡献点。P25 messageRenderers 返回原生 block，不能直接承载 SVG WebView，因此聊天内嵌图解、自动解析历史消息、独立平移覆盖层不纳入本次 MVP。

## 渲染边界

- 固定 `pele@1.7.0`，复用已校验的官方包，页面离线加载 vendor ESM，保留完整上游许可。
- 只在用户主动点击后渲染，不进行逐 token 重绘。图解源码不作为程序执行，也不透传配置/init 指令。
- SVG 以图片上下文显示，不能把源文本或未清理 SVG 插入页面 DOM。插件无网络、文件、子进程或工作区读取需求，沿用宿主 CSP。
- 固定渲染选项，错误使用纯文本呈现，出错时保留源码供修改并撤下旧图。
- 图片上下文不继承外层 CSS 变量，所以将宿主白名单主题颜色落实到 SVG；主题切换重新生成预览。
- 页面使用宿主中英语言、语义色与字体。窄窗口上下排列；大图在预览区域内滚动。
- MVP 源码只在当前页面内存中，页面回收后不保证保留。不提供持久保存、SVG 链接跳转或图中文字选择。
