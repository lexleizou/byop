## 1. 外壳：卡片化分区

| 项 | 规则 |
|---|---|
| 画布 | Light `#fcfbf9`，Dark `#211f1c`（Onevra `background`） |
| 卡片 | 顶栏、侧栏、主区、展开时的任务面板各为一张卡；表面 Onevra `surface` |
| 间距 | 卡片之间及画布四周 8px（`workbench.shell.gap`） |
| 圆角 | 12px（Onevra `bubbleRadius`） |
| 边框 | 1px `border`；高对比度保留边框并加深 |
| 阴影 | 三级 token：`shadow.container`（外壳卡）、`shadow.card`（内容卡、插件卡）、`shadow.overlay`（浮层）。消息、工具行、HUD 不加阴影 |
| 裁剪 | 外层负责宽度动画、背景、边框、阴影且不裁剪；内层负责 `Clip` 与滚动 |
| 安全区 | 顶栏内容避让 macOS 红绿灯与 Windows 标题按钮 |

## 2. 顶栏

- 删除 `P9C` 阶段标签；“关于”显示真实版本与 build。
- 中间：Chat 页显示当前会话标题，14px 单行省略；其他页面显示页面名。
- 仅空白背景可拖动窗口；品牌、标题、菜单、按钮都不触发拖动。
- 标题旁菜单：**重命名**、**根据上下文重新命名**。

### 自动命名（方案 A）

1. 首次发送后立即显示本地临时标题（截取首条消息）。
2. 首个成功 `agent_settled` 后，后台运行隔离一次性请求：
   `pi --print --no-session --no-tools --no-extensions --no-skills --no-context-files --no-prompt-templates --no-mcp --thinking off`，超时 20 秒。
3. 结果通过 RPC `set_session_name` 写回；请求绑定 session path/id 与 generation，切换会话、手动改名、断开、超时则丢弃。
4. 已有 Pi 名称不自动覆盖；“根据上下文重新命名”是用户主动操作，可以覆盖。
5. 失败静默保留原名。长度：硬上限 80 字符；自动名中文 ≤12 字或英文 ≤8 词。

## 3. 侧栏底部

- 最底一行：左侧 Pi 状态点（8px）+ 简短状态词，右侧 32×32 设置齿轮。删除大状态卡和分隔线。
- 收起态：状态点在上、齿轮在下，各 36×36。
- 点击状态点弹出浮层：状态、CLI 路径、版本、错误（如有）、“重新连接”。
- 都有 tooltip、焦点态和无障碍名称。

## 4. 通知

- 删除每轮结束的 “Pi finished and is ready for another message” 横幅。
- 连接错误改为独立状态 `piError`（错误码 + 原文），不再借用 `s.notice`；`setPage` 不会清掉它。
- Chat 页：时间线上方一条提示，包含本地化错误和“重新连接”；空白页不再重复错误。其他页面只靠状态点。
- 错误码与语言键：`errorPiNotFound`、`errorPiNotExecutable`、`errorPiHandshakeTimeout`、`errorPiExited`、`errorPiUnknown`（未知错误附原文）。
- 普通通知仍用现有横幅，可关闭。

## 5. 输入区

- **Bug**：一轮结束后 composer 底部被窗口截断。修复后，composer、操作行、HUD 形成稳定底部区域，时间线独立滚动。
- **排队/插话**：空闲时隐藏；Pi 运行时在输入区显示分段控件，记住上次选择；停止按钮独立；`⌘/Ctrl+Enter` 本次使用相反模式。删除设置页的“运行中发送”卡。插话说明：Pi 会在当前回复及其工具调用结束后处理该消息，不会立即打断。发送失败保留草稿。
- **HUD**（只替换左侧 `Pi CLI` 胶囊）：
  - git 分支（显示为 `main` 或 `(main)`），不显示 cwd 路径；
  - `↑输入 ↓输出 R缓存读 W缓存写`；
  - 累计缓存命中率，标签“缓存命中（累计）”，与 CLI 最近一次请求的 `CH` 区分；
  - 费用 `$0.000`，已知订阅显示 `(sub)`；
  - 上下文 `% / 窗口`，开启自动压缩时加 `(auto)`，>70% warning，>90% danger；
  - 扩展 `setStatus` 按 key 存储显示。
  - 不显示模型、思考强度、会话名、正常连接状态；缺失值显示 `?`。
  - 刷新时机：连接、切换会话、模型或思考变化、`agent_settled`、压缩、重连；切换时先清空。
  - 保留停止、重试、压缩 shimmer 与 follow-up `Tab · Esc` 提示；窄窗口 HUD 换到独立一行。

## 6. 时间线

- 连续的“Ran n tools”行之间去掉大块空白：相邻纯工具组间距从 48px 压到 8px。
- 只压缩相邻工具组，不跨 assistant 文本合并。

## 7. 设置

- **旧版迁移（方案 A）**：启动后异步扫描；只有发现可导入数据时，Chat 顶部显示一次性提示“发现旧版 Pi Agent Desktop 设置 · 导入 / 暂不导入”；持久化 `legacyMigrationPromptDismissed`；不删除旧数据；设置页仅在旧数据存在时保留文字链接“重新导入旧版数据”；扫描失败只在设置页显示。删除设置页常驻迁移卡。
- **外部 Pi CLI 卡**：保留状态、连接按钮、CLI 路径、版本；原始错误放进可折叠详情；删除模型、会话、运行状态行。
- “工作台偏好”中的纯技术行保留在可折叠“诊断”中。

## 8. 插件卡

- 统一高度 token `pluginCard.defaultHeight = 236`（以第一张卡视觉比例为基准），宽度 320–360。
- 固定结构：图标+状态 → 名称 → 2 行描述 → 能力摘要（1 行）→ 状态摘要/错误摘要（1 行）→ 底部行（主操作 + “详情”）。
- 插件 ID、运行时、调用次数、完整权限、全部命令、WebView 信息放入详情浮层（`shadow.overlay`）。
- Hover 只改变背景、边框或阴影，不改变尺寸。

## 9. 通用

- 减少动效设置作用于侧栏、详情浮层和列表过渡。
- 需检查中英文、明暗主题和窄窗口。
